# notes

Findings that are worth keeping but do not belong in `CLAUDE.md` (what the app
is and why) or `AGENTS.md` (who may touch what).

A session's own scratchpad is private to that session and dies with it — two
sessions' context was lost that way on 2026-11-05. If a measurement took real
work to produce, it goes here and gets committed, or it is not knowledge, just
something a session briefly knew.

One file per finding. Name it `<role>-<topic>.md`. Say what was measured and
how, and keep claims separate from inferences — this project has twice had a
confident mechanism turn out to be wrong while the symptom was real.
